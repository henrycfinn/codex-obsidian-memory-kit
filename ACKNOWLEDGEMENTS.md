# Acknowledgements

Agentic Librarian is an independent open-source implementation built from public ideas and documented APIs.

Conceptual influences include:

- **Hermes Agent / Nous Research** — the native plugin system and built-in `llm-wiki` pattern this project is designed to wrap rather than fork: https://github.com/NousResearch/hermes-agent
- **Andrej Karpathy's LLM Wiki pattern** — the compiled, interlinked Markdown knowledge-base idea referenced by Hermes' `llm-wiki` skill: https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f
- **Wanderloots' public Agentic Librarian / trusted LLM Wiki material** — the Bronze → Silver → Gold framing and emphasis on a deterministic trust boundary behind selective human review.
- **The Librarian by Code Ministry** — public documentation demonstrating useful risk-tiered proposal/review and stale-change patterns: https://github.com/code-ministry-ltd/the-librarian
- **QMD by Tobi Lütke** — optional local retrieval/index infrastructure: https://github.com/tobi/qmd

No member-only/paywalled kit files or source code are included in this repository. The implementation here was written independently against public descriptions and Hermes/QMD interfaces.

All named projects remain the property of their respective maintainers. Inclusion here is acknowledgement, not an assertion of affiliation or endorsement.
