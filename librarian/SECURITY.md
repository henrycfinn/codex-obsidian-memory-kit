# Security Policy

## Supported versions

Security fixes are targeted at the latest released version while the project is pre-1.0.

## Reporting

Please report a suspected vulnerability privately through GitHub's private vulnerability reporting feature when enabled on the repository. Do not include real user knowledge-base content, tokens, credentials, or private proposal data in a public issue.

If private reporting is unavailable, open a minimal public issue requesting a secure contact channel without disclosing exploit details.

## Scope reminder

Agentic Librarian is a knowledge-integrity guardrail inside Hermes, not an operating-system sandbox. Review [`docs/security.md`](docs/security.md) before reporting behavior that depends on arbitrary external processes writing files with the user's own permissions.
